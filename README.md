# All the girls

Настольное приложение для наблюдения за визуальными и речевыми сигналами собеседника:
мимикой, глазами и взглядом, покраснением кожи и речью — в реальном времени, локально,
относительно индивидуального исходного состояния человека.

> **Сигналы — не выводы.** Показатели описывают наблюдаемые изменения лица, взгляда и речи.
> Они не определяют эмоции, мысли, намерения, ложь или «подозрительность». Отведённый взгляд
> не доказывает неуверенность, покраснение — смущение. Свет, камера, усталость и сама
> ситуация дают такие же изменения.

## Запуск

```bat
run.bat
```

или с консолью (видны сообщения модулей):

```bat
.venv_main\Scripts\python.exe app.py
```

Прежний интерфейс в окне OpenCV (источник выбирается в консоли) сохранён:

```bat
.venv_main\Scripts\python.exe app.py --classic
```

Приложение можно запускать из любой папки: пути к `models/`, `results/`, `logs/` и
`settings.json` считаются от папки проекта.

### Установка зависимостей (если окружения нет)

```bat
py -3.9 -m venv .venv_main
.venv_main\Scripts\python.exe -m pip install -r requirements-main.txt
```

Нужны модели:

* `models/face_landmarker.task` — MediaPipe Face Landmarker (лежит в проекте);
* Whisper (`small` по умолчанию) — берётся из кэша Hugging Face (`%USERPROFILE%\.cache\huggingface`),
  при отсутствии скачивается один раз, если это разрешено в настройках;
* `cointegrated/rut5-small-normalizer` — необязательная коррекция текста (нужен пакет `sentencepiece`).

## Интерфейс

* **Верхняя панель** — логотип, состояние (готово / анализ идёт / пауза / ошибка), источник видео
  (камера, видеофайл, экран), время сессии, участник, индикаторы приватности
  (камера, микрофон, анализ, запись на диск) и настройки.
* **Видео** — главный элемент экрана. Поверх него — ненавязчивая подсветка лица (уголки рамки),
  контуры глаз и радужки (при закрытых глазах контур краснеет), при желании — 478 точек сетки,
  субтитры, предупреждения о качестве кадра и баннер калибровки.
* **Динамика сессии** — дорожки показателей во времени: серая полоса — обычный диапазон,
  пунктир — база, красным — выход за диапазон. Сверху — события (быстрые изменения мимики,
  фразы, калибровки), штриховка — время без лица. Наведение мышью показывает значения в момент времени.
* **Наблюдения** — лицо, взгляд, моргание, выражение лица, активность мимики, покраснение,
  речь, отклонение от базы. У каждой строки — подсказка с ограничениями метода.
  Если показатель не определён, выводится «Нет данных».
* **Речь и субтитры** — распознанные фразы с метками времени и текущая строка.
* **Нижняя панель** — Начать / Пауза / Продолжить, Завершить, Перекалибровать, Журнал,
  История, Настройки.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | начать анализ / пауза / продолжить |
| Ctrl+E | завершить сессию |
| Ctrl+R | перекалибровать всё (нейтральное лицо, цвет кожи, личная база) |
| C / R / B | отдельно: мимика / покраснение / личная база |
| H | скрыть или показать подсветку лица |
| F или F11 | полный экран |
| Ctrl+J / Ctrl+H / Ctrl+, | журнал / история / настройки |
| T / L / N | ручная разметка «правда» / «ложь» / снять (если включена в настройках) |

## Что и как измеряется

| Показатель | Как считается | Ограничения |
|---|---|---|
| Лицо | MediaPipe Face Landmarker, 478 точек; качество кадра по размеру лица, яркости, резкости | очки, профиль, сильная тень |
| Взгляд | положение радужки относительно уголков глаз; доля времени «не в центр» за 15 с | это направление относительно камеры, а не внимание |
| Моргание | раскрытие глаз (EAR), частота за минуту (после 15 с с лицом), длительность закрытия | порог EAR фиксирован (0,21), быстрые моргания у узких глаз могут не засчитываться |
| Выражение лица | доминирующее движение (улыбка, рот, брови, прищур) относительно нейтральной калибровки | описание мышц, а не эмоции |
| Активность мимики | скорость изменения мимических показателей, сглаженная за ~1 с; быстрые скачки — события | высокая при разговоре и смехе |
| Покраснение | цвет кожи щёк, носа, лба относительно калибровки (баланс белого по кадру) | сильно зависит от света и автоэкспозиции |
| Отклонение от базы | сводный индекс отличий мимики, моргания, взгляда и речи от личной базы (первые 40 с) | не детектор лжи, стресса или эмоций |
| Речь | faster-whisper локально, фраза фиксируется, когда два распознавания совпали | Whisper ошибается на шуме и редких словах |

## Приватность

* Всё выполняется на этом компьютере; видео и звук никуда не отправляются.
  Интернет нужен только для однократной загрузки отсутствующей модели (можно запретить в настройках).
* Микрофон включается только во время анализа и выключается на паузе.
* По умолчанию сохраняются только числовые показатели (`analysis_log.csv`), текст субтитров
  и итоги (`summary.json`) — в `results/<источник>_<дата>_<время>/`. Каждый пункт отключается
  в настройках; если всё выключено, папка сессии не создаётся.
* Кадры не сохраняются. Обработанное видео пишется только для видеофайлов и только при явном
  включении в настройках.
* Историю можно просмотреть и удалить в окне «История».
* В режиме «Экран» окно программы исключается из захвата экрана.

## Структура

| Файл | Назначение |
|---|---|
| `app.py` | точка входа; классический режим OpenCV (`--classic`) |
| `analysis_pipeline.py` | покадровый конвейер анализа и производные показатели (общий для обоих интерфейсов) |
| `speech_engine.py` | загрузка моделей речи и потоковое распознавание |
| `session_timeline.py`, `session_history.py` | временные ряды и итоги сессии; история сессий |
| `settings_store.py`, `app_paths.py` | настройки и пути проекта |
| `gui/` | настольный интерфейс PySide6: окно, сцена видео, наблюдения, шкала, диалоги, фоновый поток |
| `eye_tracker.py`, `mimic_analyzer.py`, `micro_expression.py`, `redness_analyzer.py`, `quality_analyzer.py`, `suspicion_analyzer.py`, `neural_face_analyzer.py` | модули анализа |
| `whisper_subtitle.py`, `text_correction.py`, `audio_module.py`, `subtitle_storage.py` | речь и звук |
| `analysis_logger.py`, `evaluate_lie_signals.py` | журнал CSV и исследовательская оценка ручной разметки |
| `tests/test_core.py` | проверки ядра |

Не подключены к приложению: `emotion_analyzer.py`, `emotion_bridge.py`, `emotion_worker.py`
(DeepFace в отдельном окружении `.venv_emotion`), `video_analysis_worker.py`, `face_tracker.py`
(использует `mediapipe.solutions`, которого нет в MediaPipe 0.10.33).
